# Data Cleaning & Exploratory Data Analysis

This folder contains the data preparation workflow, analysis notebooks, cleaned dataset, project documentation, presentation material, and visual findings for the Workforce Insights Dashboard.

## Folder Contents

```text
Data_Cleaning/
├── CleanedDataset.csv             # Dataset after cleaning and validation
├── dashboard.pbix                 # Power BI workforce insights dashboard
├── Data Integration.ipynb         # Data integration workflow
├── Data_Cleaning_EDA.ipynb        # Data cleaning and exploratory analysis
├── Project Report.pdf             # Complete project report
├── Presenttion PPT.pptx           # Project presentation deck
├── Documents/                     # Project planning and testing spreadsheets
│   ├── Agile Template.xlsx
│   ├── Unit Test Plan.xlsx
│   └── Defect Tracker.xlsx
└── Images/                        # EDA charts and key findings
```

## Deliverables

| File | Description |
| --- | --- |
| [Project Report](Project%20Report.pdf) | Complete project report covering the solution, methodology, findings, and outcomes. |
| [Cleaned Dataset](CleanedDataset.csv) | Workforce dataset after cleaning, transformation, and validation. |
| [Power BI Dashboard](dashboard.pbix) | Interactive workforce insights dashboard built with Power BI. |
| [Data Integration Notebook](Data%20Integration.ipynb) | Notebook documenting the data integration workflow. |
| [Data Cleaning and EDA Notebook](Data_Cleaning_EDA.ipynb) | Notebook containing data cleaning steps, exploratory analysis, and visualizations. |
| [Project Presentation](Presenttion%20PPT.pptx) | Presentation deck summarizing the project and its results. |
| [Documents](Documents/) | Planning and testing spreadsheets; additional sheets will be added later. |
| [Images README](Images/README.md) | Notes for the exported EDA images and key findings. |

## Project Documents

The `Documents/` folder is reserved for project management, testing, and quality tracking resources:

| Spreadsheet | Purpose |
| --- | --- |
| [Agile Template](Documents/Agile%20Template.xlsx) | Agile planning, sprint tracking, and project coordination. |
| [Unit Test Plan](Documents/Unit%20Test%20Plan.xlsx) | Test scenarios, expected results, and execution status. |
| [Defect Tracker](Documents/Defect%20Tracker.xlsx) | Defect logging, prioritization, ownership, and resolution tracking. |

Additional worksheets and supporting sheets can be added to these workbooks as the project progresses.

## Workflow

```text
Raw workforce data
	|
	v
Data cleaning and validation
	|
	v
CleanedDataset.csv
	|
	v
Exploratory data analysis and visual findings
	|
	v
Reports, presentation, dashboard, and RAG insights
```
