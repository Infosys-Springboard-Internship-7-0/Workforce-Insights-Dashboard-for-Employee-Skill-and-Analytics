# Contributing Guide

Thank you for contributing to the Workforce Insights Dashboard for Employee Skill and Analytics.

## How to Contribute

1. Fork the repository and create a working branch.
2. Review the README, project scope, and current contributor roster.
3. Make your changes in a focused commit.
4. Add your details to [contributors.json](contributors.json) using this structure:

```json
{
  "name": "your_name",
  "contact": "mobile_number/email",
  "course": "your_course",
  "college": "your_college",
  "address": "your_address",
  "github_username": "your_github_username"
}
```

5. If you add yourself to `contributors.json`, keep the values accurate and consistent.
6. Verify that the README contributor table updates through the GitHub workflow.
7. Open a pull request with a clear summary of your contribution.

## Contributor Notes

- Use only one entry per contributor.
- Keep the `github_username` field aligned with the GitHub profile used for the contribution.
- Ensure contact information is valid and up to date.
